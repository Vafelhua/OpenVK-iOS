# OpenVK iOS

Нативный iOS-клиент OpenVK для iOS 12.0+, телефонная ориентация, только arm64. Написан на UIKit без SwiftUI и SF Symbols. Целевая платформа: iPhone 6 и выше.

## Возможности
- Авторизация (логин/пароль) на произвольном инстансе OpenVK
- Лента новостей (newsfeed), поиск по новостям и пользователям
- Диалоги и чат с поддержкой вложенных фото
- Друзья, группы, профиль, стена пользователя/сообщества
- Музыкальный плеер (список аудио, поиск)
- Комментарии к записям, лайки, репосты
- Настройки: выбор инстанса, тёмная/светлая тема, выход из аккаунта

## Сборка
Требуется macOS с Xcode 12+ (рекомендуется Xcode 14).

1. Откройте проект:
```bash
open OpenVK-iOS/OpenVK.xcodeproj
```
2. Выберите схему `OpenVK`, целевое устройство (iPhone 6 Simulator или реальное iPhone с iOS 12+)
3. Соберите и запустите (`Cmd+R`)

Настройки сборки:
- `IPHONEOS_DEPLOYMENT_TARGET = 12.0`
- `ARCHS[sdk=iphoneos*] = arm64`
- `TARGETED_DEVICE_FAMILY = 1`
- `PRODUCT_BUNDLE_IDENTIFIER = org.openvk.openvkios`
- `SWIFT_VERSION = 5.0`

## Конфигурация
По умолчанию используется `https://api.openvk.org/method/`. Можно сменить инстанс в разделе «Настройки» приложения.

OpenVK API версии `5.106`, `client_id = 5027722`.

## Хранение данных
- Токен доступа — в Keychain
- ID пользователя, выбранный инстанс, тема — в `UserDefaults`
- Кэш изображений — в `Caches/OpenVKImages` (дисковый + память)

## Отладка на iOS 12
Проект написан без `async/await`, SwiftUI, SceneDelegate, использует только UIKit. Иконки отрисовываются текстовыми глифами (fallback вместо SF Symbols).

## Известные ограничения
- Long Poll может деградировать до периодического опроса на некоторых инстансах
- newsfeed.getGlobal используется с fallback, если недоступен на выбранном инстансе
- Декодирование JSON гибкое (числа/строки), учитывает различия между OpenVK и VK
